# PROJECT

Lumen (also called GlowDesk) is a dark-mode desktop control center for WiZ, GE Cync and Hubspace smart lights, built with Electron. It ships as a Windows build (installer + portable exe) and a Mac build (dmg + zip) from this one repo.

Features: per-brand light control, rooms, groups, scenes, automation, music/screen-reactive Effects (Pulse, Spectrum, Party, Screen match, Aurora, Candle), Projection Studio (mapped shapes, 41 palette/audio-driven animations, Low/Medium/High render quality with adaptive fallback, and lights following with restore-on-stop), and TouchDesigner Studio for local-model-assisted animation authoring through TDMCP. Details: README.md and TOUCHDESIGNER.md.

Owner workflow: the owner tests the app and reports problems/ideas; Claude and Codex do the engineering and hand off through this repo (see AGENTS.md).
